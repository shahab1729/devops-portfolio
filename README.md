## 🖥️ About This Web Application

This repository houses the source code for my interactive DevOps portfolio web application. It features:
- **Interactive Developer Terminal**: Command-line simulation (`docker ps`, `kubectl get pods`, `git status`, `systemctl status nginx`, `aws s3 ls`, `uname -a`, etc.)
- **Dark Mode DevOps Design**: Terminal-inspired aesthetic built with React, Vite, and Tailwind CSS.
- **GitHub Activity Feed**: Real-time project commits and contribution stats showcase.
- **Automated Deployment**: GitHub Actions pipeline automatically builds and deploys updates to GitHub Pages on every push to `main`.

### 🚀 Local Development Setup

1. **Clone the Repository**
   ```bash
   git clone https://github.com/shahab1729/devops-portfolio.git
   cd devops-portfolio
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for Production**
   ```bash
   npm run build
   ```
